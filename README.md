# 基金业绩排名计算

一个纯前端基金业绩排名计算工具。用户上传基金 Excel / CSV 数据后，输入基金代码或基金简称，系统会按指定分类口径生成可比样本池，并按所选业绩指标计算排名、百分位和备注。结果支持多统计周期横向展示、列拖拽调整顺序，并可导出 Excel。

## 功能概览

- 支持上传 `.xlsx`、`.xls`、`.csv` 文件。
- 支持按基金代码或基金简称批量查询，每行一个。
- 支持核心对比口径：一级分类、二级分类、三级分类、评级分类 / 最终评级分类。
- 支持排序指标：净值增长率（%）、超额增长率（%）。
- 支持简称关键词二次筛选样本池。
- 支持自动识别统计周期，例如近一年、近两年、近三年、过去一年、过去两年、过去三年、最近三年等。
- 支持多选统计周期，并将近一年、近两年、近三年等结果横向展示为列。
- 支持读取 Excel 中已有排名列，并将最近三年已有排名单独输出到“已给排名”列。
- 支持输出 5 年评级、3 年评级。
- 支持结果表列顺序鼠标拖拽调整。
- 支持导出 Excel。
- 全部计算在浏览器本地完成，不上传数据到服务器。

## 使用方法

1. 打开 `index.html`，或打开 `outputs/github-pages发布包/index.html`。
2. 上传基金 Excel / CSV 文件。
3. 在“基金代码 / 简称”输入框中输入一个或多个基金代码或简称，每行一个。
4. 选择核心对比口径：一级分类、二级分类、三级分类或评级分类。
5. 选择排序指标：净值增长率（%）或超额增长率（%）。
6. 可选输入基金简称关键词，例如“中证1000”“沪深300”。
7. 选择一个或多个统计周期。
8. 点击“开始计算”。
9. 在结果区查看排名结果，必要时拖动表头调整列顺序。
10. 点击“导出 Excel”导出结果。

## Excel 字段要求

### 必要字段

至少需要以下字段：

| 类型 | 字段 |
| --- | --- |
| 基金代码 | `基金代码`、`产品代码` 等 |
| 基金名称 | `基金名称`、`基金简称`、`产品简称` 等 |

### 分类字段

分类字段至少建议提供一种，支持以下字段：

| 分类口径 | 可识别字段示例 |
| --- | --- |
| 一级分类 | `一级`、`一级分类`、`基金一级分类` |
| 二级分类 | `二级`、`二级分类`、`基金二级分类` |
| 三级分类 | `三级`、`三级分类`、`基金三级分类` |
| 评级分类 | `评级分类`、`最终评级分类` |

优先建议在源文件中提供 `最终评级分类`，该列会作为“评级分类”口径的主要取池依据。

### 业绩字段

支持常见业绩字段：

| 指标 | 可识别字段示例 |
| --- | --- |
| 净值增长率 | `净值增长率(%)`、`净值增长率[%]`、`最近三年净值增长率` |
| 超额增长率 | `超额收益率(%)`、`超额增长率(%)`、`最近三年超额收益率[%]` |

支持单行表头，也支持多行合并表头。例如：

| 第一行 | 第二行 |
| --- | --- |
| `最近三年（2022.08.01-2025.07.31）` | `净值增长率(%)` |
| `最近三年（2022.08.01-2025.07.31）` | `超额收益率(%)` |

### 已有排名字段

工具可以识别已有排名字段，例如：

- `近一年业绩排名`
- `近一年超额排名`
- `近两年业绩排名`
- `近两年超额排名`
- `近三年业绩排名`
- `近三年超额排名`
- `最近三年排名`
- `最近三年超额排名`

排名格式支持：

- `37/104`
- `前36% (37/104)`
- `2,149/4,109`
- `前53% (2,149/4,109)`

## 计算口径

### 样本池

样本池按以下顺序生成：

1. 根据目标基金的所选分类口径确定同分类基金池。
2. 如果填写了基金简称关键词，再按关键词筛选基金名称。
3. 剔除当前统计周期下没有所选指标数据的基金。

### 排名

- 按所选指标降序排列。
- 指标值越高，名次越靠前。
- 相同收益率使用相同名次。
- 后续名次按实际排序位置计算。

### 百分位

百分位排名计算公式：

```text
ceil(名次 / 有效样本数 * 100)
```

例如：

```text
37 / 104 = 35.58%，输出为 前36%
```

### 已给排名

如果 Excel 中识别到 `最近三年排名` 或 `最近三年超额排名`，结果表会单独增加一列：

```text
已给排名
```

该列用于展示源文件中已提供的最近三年排名。

注意：`已给排名` 不会覆盖原本的 `近三年业绩排名` / `近三年超额排名`。原本的近三年结果仍按当前选择的分类口径和指标逻辑计算。

### 异常备注

以下情况会写入备注，并随 Excel 导出：

- 找不到基金。
- 目标基金缺少所选分类。
- 目标基金没有所选指标数据。
- 有基金因缺少指标数据被剔除。
- 有效样本数不足 10 只。
- 目标基金未命中简称关键词。
- 目标基金不在最终可比样本池。

## 输出字段

结果表主要包含：

- 产品代码
- 产品简称
- 近一年业绩排名 / 超额排名
- 近两年业绩排名 / 超额排名
- 近三年业绩排名 / 超额排名

- 5 年评级
- 3 年评级

## GitHub Pages 发布

如果需要生成一个所有人都能打开的网页链接，可以使用 GitHub Pages。

推荐上传文件：

```text
outputs/github-pages发布包/index.html
```

操作步骤：

1. 打开 GitHub 仓库。
2. 上传或替换仓库根目录下的 `index.html`。
3. 打开仓库 `Settings`。
4. 找到 `Pages`。
5. Source 选择 `Deploy from a branch`。
6. Branch 选择 `main`，目录选择 `/root`。
7. 保存后等待 GitHub Pages 部署完成。

部署完成后，访问地址通常为：

```text
https://你的用户名.github.io/你的仓库名/
```

如果以后修改了网页，需要重新上传新版 `index.html`，GitHub Pages 才会更新。

## 常见问题

### 1. 为什么识别不到统计周期？

请检查表头是否包含周期关键词，例如：

- 近一年
- 近两年
- 近二年
- 近三年
- 过去一年
- 过去两年
- 过去三年
- 最近一年
- 最近两年
- 最近三年

如果是多行表头，请确保周期行和指标行在同一个表头区域内。

### 2. 为什么某只基金没有排名？

常见原因：

- 找不到基金代码或简称。
- 目标基金缺少当前分类字段。
- 目标基金没有当前周期的所选指标。
- 关键词筛选后目标基金不在样本池中。
- Excel 中该产品本身没有对应排名或收益率。

### 3. 为什么“已给排名”和“近三年排名”不一样？

这是正常情况。

`已给排名` 来自 Excel 中已有的 `最近三年排名` 或 `最近三年超额排名`。

`近三年业绩排名` / `近三年超额排名` 则按网页当前选择的分类口径、关键词筛选和指标数据计算。

### 4. 为什么导出的 Excel 列顺序和页面一样？

页面支持拖动表头调整列顺序。导出 Excel 时会按页面当前列顺序导出。
